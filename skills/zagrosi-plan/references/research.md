# Research

Use `rg` to inspect relevant code/callers, tests, config, and CI. Fetch current
external contracts using repository-required documentation tools. Record only
`evidence -> implication -> decision` in the canonical plan; separate research
files only for independent reuse/audit.

Delegate bounded questions; merge findings once. Never end a turn while a
[delegated agent](../../zagrosi-forge/references/providers.md#delegated-agents) still runs.
Stop researching when remaining unknowns cannot change implementation. Ask only
for unresolved material choices.
